High Level overview of the reduced instruction set assembly

move - mov
takes l/r/u/d for left, right, up, down

looks like: mov l 

rotate - rot
takes l/r for left, right

looks like: rot l

grab - grb
no parameters

looks like: grb

drop - drp
no parameters

looks like drp

jump - jmp 
takes a label

looks like jmp loop_start

labels: text
any kind of word followed by a colon

looks like loop_start:

add/sub/mul/div - add, subtract, multiply, divide
command plus two registers
looks like add r1 r2

By default result is stored to r0

write - wrt
writes to register, rather than using the normal convention of mov since that overlaps

compare - cmp
takes 2 registers to compare, form of reg1 - reg2

looks like cmp reg1 reg2

wait - wait
does nothing

Registers:

r0 - default store, math operations store the results to r0
r1, r2: general purpose registers
cmp - where compare flags are stored


## More register Stuff Examples + Explanations

wrt r0 10    # Write literal value
wrt r0 r1    # Copy value from r1 to r0
wrt r1 r2    # Copy value from r2 to r1
wrt r0 cmp   # Copy cmp value to r0
wrt cmp r0   # Copy r0 value to cmp


# Register + Register
add r0 r1    # r0 = r0 + r1

# Register + Literal
add r0 5     # r0 = r0 + 5
sub r1 10    # r0 = r1 - 10

# Literal + Register
mul 3 r2     # r0 = 3 * r2

# Literal + Literal
div 100 4    # r0 = 100 / 4
cmp 5 10     # cmp = (5 < 10) ? -1 : 0
