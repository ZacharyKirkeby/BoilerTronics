# BoilerTronics

BoilerTronics is a **factory automation and logistics simulation game** developed in **Godot** as part of Purdue University's **CS 307 – Software Engineering I** course. Players design automated production systems using conveyors, pipes, and robotic claws, as well as programming each component of the factory using a custom assembly instruction set to transport resources between machines and complete manufacturing objectives.

The project focuses on **modular game architecture, user interface design, and collaborative software development using Agile methodologies**.

---

## Overview

In BoilerTronics, players construct automated factory systems to move and process resources efficiently. The game challenges players to optimize their layouts and manage item flow through a network of machines and transport systems.

Players can:

- Place and configure **conveyors, pipes, and robotic claws**
- Route resources between machines
- Build efficient automated production systems
- Track progress through **achievements and objectives**

The goal is to design a functioning production line capable of meeting increasingly complex manufacturing requirements.

## Features

### Automation Systems

- Custom assembly instruction set.
- Conveyor belts for transporting items
- Pipes for fluid transfer
- Robotic claws for item pickup and placement
- Modular machine components

### Gameplay Mechanics

- Factory layout construction
- Resource routing and logistics
- Objective-based progression
- Achievement tracking

### User Interface

- Interactive **object placement system**
- Game menus and navigation
- Inventory and build menus
- Dynamic UI feedback

### Technical Features

- Modular object system for factory components
- Scene-based architecture using Godot
- Event-driven gameplay systems
- Cross-platform game framework

## Development Process

The project was developed using an **Agile Scrum workflow** over multiple sprints.

Team practices included:

- Weekly sprint planning and reviews
- GitHub branching and pull request workflow
- Task tracking through user stories
- Collaborative feature development

The team focused on building maintainable and extensible systems while iterating on gameplay mechanics.
